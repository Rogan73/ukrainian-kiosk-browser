# Ukranian Kiosk Browser

Нативний Android-додаток, який працює як автономний веб-оглядач у режимі кіоску (Kiosk-style browser). Він призначений для відображення веб-сторінок у повноцінному повноекранному режимі без жодних елементів керування браузера, адресних рядків чи постійних системних панелей Android. Усі елементи інтерфейсу програми виконані українською мовою.

---

## 🚀 Основний функціонал

*   **Чистий Fullscreen (Immersive Sticky Mode):** Повна відсутність верхніх та нижніх панелей програми. Системні кнопки навігації Android (Назад, Додому, Меню) та рядок стану повністю приховані й з'являються лише тимчасово при свайпі знизу вгору, після чого автоматично зникають.
*   **Прихована бічна панель (Left Navigation Drawer):** Викликається свайпом від лівого краю екрана. Панель оптимізована для запобігання конфліктів із жестами всередині WebView і містить лише три фіксовані пункти:
    1.  **Налаштування** — перехід до екрана керування сайтами.
    2.  **Список** — динамічний список збережених назв сайтів для швидкого перемикання між ними.
    3.  **Про програму** — модальне вікно з інформацією про додаток.
*   **Розумний запуск (Routing Logic):** 
    *   Якщо база даних порожня, додаток автоматично відкриває екран Налаштувань для додавання першого сайту.
    *   Якщо сайти є, додаток миттєво завантажує сторінку, яка відкривалася останньою (використовує збереження історії сесії).
*   **Гнучке налаштування для кожного сайту (CRUD):** Для кожного веб-ресурсу в базі даних можна індивідуально налаштувати:
    *   **Дозвіл/заборону повороту екрана** (фіксація в портретному режимі або вільна орієнтація).
    *   **Повноекранний режим** (активація або деактивація приховування системних панелей).
    *   **Керування звуком** (дозвіл або блокування відтворення аудіо).
    *   **Масштабування сторінки** (дозвіл на pinch-to-zoom із приховуванням стандартних системних кнопок +/-).
*   **Інтегрований QR-сканер:** Можливість миттєво внести URL-адресу сторінки за допомогою сканування QR-коду через камеру (з автоматичним запитом дозволів українською мовою).

## 🛠 Технологічний стек (Рекомендований)

*   **Платформа:** Android (API 21+)
*   **База даних:** Room Database / SQLite (для збереження конфігурацій сайтів)
*   **Локальне сховище:** SharedPreferences (для фіксації останнього відвіданого `site_id`)
*   **Компоненти UI:** `DrawerLayout`, повноекранний `WebView` з кастомним `Touch-gesture` перехоплювачем, `WindowInsetsControllerCompat` для керування системними панелями.
*   **Сканер кодів:** Google ML Kit Barcode Scanning / CameraX (легковажне нативне розпізнавання без сторонньої реклами).

## 📂 Структура бази даних (`SiteConfig`)

| Поле | Тип даних | Опис |
| :--- | :--- | :--- |
| `id` | Integer (PK) | Автоінкрементний ідентифікатор запису |
| `name` | String | Назва сторінки (відображається в меню "Список") |
| `url` | String | Повне посилання на веб-ресурс |
| `allowRotation` | Boolean | Дозвіл на зміну орієнтації екрана |
| `isFullscreen`| Boolean | Активація Immersive Sticky режиму для цього сайту |
| `isSoundEnabled`| Boolean | Дозвіл на відтворення медіа-звуків |
| `isZoomEnabled` | Boolean | Дозвіл на ручне масштабування сторінки |

## ⚙️ Поведінка інтерфейсу

1.  **Перемикання сайту:** При виборі сайту з меню "Список", бічна панель закривається, конфігурація `WebView` та Activity миттєво перебудовується під налаштування цього сайту (зміна орієнтації, приховування панелей тощо), і починається завантаження URL.
2.  **Реактивність даних:** Будь-які зміни (додавання, видалення, редагування) на сторінці "Налаштування" одразу ж оновлюють вміст підменю "Список" у реальному часі.
